# Hospital Management System

## 1. Project Overview

The Hospital Management System is a Python-based application designed to help manage hospital information and daily operations. It provides features for managing patients, doctors, appointments, payments, medical records, prescriptions, and appointment history.

The application uses JSON files to store data.

## 2. Features

* User Registration and Login
* Role-Based Access for Admin, Doctor, and Receptionist
* Patient Management
* Doctor Management
* Appointment Management
* Payment Management
* Patient Check-in and Check-out
* Medical Records Management
* Prescription Management
* Appointment History
* Reports and Statistics
* JSON Data Storage
* Input Validation and Exception Handling

## 3. Technologies Used

* Python
* JSON
* Visual Studio Code
* Git and GitHub

## 4. Project Structure

* `main.py` — Main application and menu navigation
* `auth.py` — User registration and login
* `models.py` — Data models
* `storage.py` — JSON data loading and saving
* `patient_service.py` — Patient management
* `doctor_service.py` — Doctor management
* `appointment_service.py` — Appointment management
* `appointment_history_service.py` — Appointment history
* `payment_service.py` — Payment management
* `checkin_service.py` — Patient check-in and check-out
* `medical_record_service.py` — Medical records management
* `prescription_service.py` — Prescription management
* `report_service.py` — Reports and statistics
* `exceptions.py` — Custom exceptions
* `data/` — JSON data files
* `screenshots/` — Application screenshots

## 5. Requirements

* Python 3
* Git (for version control)

## 6. How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

5. Follow the menu instructions to use the application.

## 7. Data Storage

The application stores information in JSON files inside the `data/` directory.

Use sample data for demonstrations. Do not publish real patient information, passwords, or other confidential data.
